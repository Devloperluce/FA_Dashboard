# 팀 로고 넣는 곳

이 폴더에 이미지를 넣으면 팀 엠블럼 대신 자동으로 표시됩니다.

- 파일 이름 = 팀 id + 확장자 (png, svg, webp, jpg) — 아래 표의 **저장할 파일 이름** 그대로 쓰면 됩니다.
- 정사각형에 가깝고 투명 배경, 256px 이상 권장
- 파일이 없는 팀은 팀 컬러 약칭 배지가 그대로 나옵니다.
- 구단 로고는 상표이므로 사용 권한을 확인하고 넣어주세요.

## 받는 방법 (위키백과)

1. 표의 링크를 열고, 오른쪽 정보 상자의 **로고 이미지**를 클릭합니다.
2. 이미지 아래 **More details**(또는 파일 이름)를 눌러 파일 페이지로 이동합니다.
3. **Original file** 링크를 열어 저장합니다. SVG가 있으면 SVG가 가장 선명해요.
4. 파일 이름을 표의 **저장할 파일 이름**으로 바꿔 이 폴더에 넣습니다. (확장자는 받은 형식 그대로)
5. 최근 엠블럼을 바꾼 구단도 있으니, 구단 공식 홈페이지 로고와 같은지 한 번 확인해 주세요.
